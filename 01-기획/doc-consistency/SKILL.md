# 설계 문서 정합성 검증기

1. 검증 대상 문서 목록을 확인한다 (2개~N개, 가변적). 문서가 명확하지 않으면 어떤 파일들을 볼지 질문한다.
2. 프론트매터(버전, 날짜, 작성자 등)가 문서 간 서로 어긋나지 않는지 확인한다.
3. 핵심 용어가 문서마다 다르게 쓰이지 않는지 확인한다 (예: 같은 개념을 다른 이름으로 부르는 경우).
4. Mermaid 다이어그램이 있다면 다이어그램과 본문 설명이 일치하는지, 문서 간 다이어그램끼리 모순되지 않는지 확인한다.
5. 문서 간 요구사항이 누락되었거나(한쪽에만 있고 다른 쪽엔 빠짐) 서로 모순되는지 확인한다.
6. 발견한 문제를 [문제 유형(프론트매터/용어/다이어그램/요구사항) / 심각도(치명적/주의) / 위치(문서명+섹션) / 내용] 형식으로 정리해서 보고한다. 심각도가 높은 것부터 보여준다.
7. 문제가 없는 문서/섹션은 나열하지 않는다 — 문제 중심으로 간결하게.
8. 사용자 확인 후 원하면 해당 문서를 직접 수정한다.
