# 문서 다듬기

1. 원하는 출력 형태를 확인한다: 마크다운 / Word(.docx) / PDF / HTML. 명시되지 않으면 질문한다.
2. **마크다운**인 경우: 표, 목차, 강조, 섹션 구분을 정리해서 읽기 좋게 다듬는다.
3. **Word(.docx)**인 경우: docx 스킬을 사용해 제목·목차·표·페이지 번호가 있는 문서로 변환한다.
4. **PDF**인 경우: pdf 스킬을 사용해 변환한다.
5. **HTML**인 경우: `references/html-style.md`에 정리된 패턴(카드형 컨테이너, 헤더 강조, 콜아웃 박스, 인쇄 버튼)을 참고해서 만든다. 색상·폰트는 문서 성격에 맞게 유연하게 고르되, 구조적 패턴은 유지한다.
6. 원본 내용(정보·구조)은 바꾸지 않고 서식만 다듬는다. 내용 자체를 고치고 싶으면 먼저 사용자에게 확인한다.
7. 완성된 파일을 사용자에게 전달한다.
