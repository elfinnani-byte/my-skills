# 세션 핸드오프 요약

1. 이번 세션에서 다룬 작업 범위를 확인한다 (대화 내용, 변경한 파일, 실행한 명령 기준).
2. 진행상황을 정리한다: 무엇을 했고, 어디까지 끝났는지.
3. 결정사항을 정리한다: 이번 세션에서 확정한 것들과 그 이유 (예: 기술 선택, 구조 변경).
4. 변경된 파일 목록을 정리한다 (git diff 또는 대화 중 언급된 파일 기준).
5. 다음 세션에서 할 TODO를 정리한다: 남은 작업, 확인이 필요한 부분, 막혀 있는 부분.
6. 위 내용을 `handoff.md` (또는 사용자가 지정한 파일)에 [진행상황 / 결정사항 / 변경된 파일 / 다음 TODO] 순서로 저장한다.
7. 대화가 길어지거나 마무리되는 분위기가 느껴지면, 요청받지 않아도 핸드오프 문서를 작성할지 먼저 제안한다.
