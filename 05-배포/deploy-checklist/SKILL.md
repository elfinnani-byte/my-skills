# 배포 전 체크리스트

1. 환경변수가 Vercel 프로젝트 설정과 로컬 `.env`에 빠짐없이 반영됐는지 확인한다.
2. 빌드가 에러 없이 성공하는지 확인한다 (`next build` 또는 해당 빌드 명령).
3. DB 마이그레이션이 있으면 실행 순서와 롤백 가능 여부를 확인한다.
4. 최근 커밋되지 않은/미배포 git diff를 분석해서 회귀 위험 부위를 식별한다: 변경된 파일과 함수, 그로 인해 영향받을 수 있는 다른 기능.
5. 4번 결과를 위험도별(높음/중간/낮음)로 분류한 마크다운 리스트로 정리한다: [파일 / 함수 / 위험도 / 이유].
6. 위 항목을 모두 통과했는지 최종 체크리스트로 요약해서 보여준다.
7. 문제가 있으면 배포를 진행하기 전에 사용자에게 먼저 알린다.
