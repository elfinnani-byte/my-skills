# 화면 디자인 검토

1. 검토 대상 화면(코드 또는 스크린샷)을 확인한다.
2. 색상·간격·타이포그래피가 프로젝트 디자인 토큰과 일치하는지 확인한다.
3. 같은 목적의 컴포넌트를 다른 방식으로 구현한 곳이 없는지 확인한다.
4. 접근성을 확인한다: 키보드 포커스 표시, 명도 대비, 대체 텍스트(alt) 여부.
5. 반응형을 확인한다: 모바일/태블릿 화면에서 레이아웃이 깨지지 않는지.
6. 문제점을 [항목 / 문제 / 이유 / 수정 제안] 형식으로 정리해서 보여준다.
