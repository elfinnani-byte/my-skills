# 화면 설계

1. 화면의 목적과 사용자가 이 화면에서 할 수 있는 액션을 확인한다.
2. 프로젝트에서 이미 쓰는 shadcn/ui 컴포넌트와 색상·간격 토큰을 우선 활용해 레이아웃을 구성한다.
3. 접근성을 고려해 설계한다: 키보드 포커스 순서, 명도 대비, 대체 텍스트가 필요한 요소.
4. 반응형을 고려해 설계한다: 모바일/태블릿에서 어떻게 재배치될지.
5. 구성안을 [영역 / 사용할 컴포넌트 / 이유]로 정리해서 보여주고 확인받는다.
