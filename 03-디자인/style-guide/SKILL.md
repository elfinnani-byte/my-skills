# 디자인 스타일 가이드

1. 기존 코드베이스가 있는지 확인한다.
2. **기존 코드베이스가 있는 경우**: Tailwind 설정, CSS 변수, 컴포넌트 파일을 스캔해서 실제 쓰이는 색상·타이포그래피·간격 값을 추출한다.
3. **처음 만드는 경우**: 프로젝트 성격과 톤(예: 관리자용 내부 툴 vs 사용자용 서비스)을 확인하고 색상·타이포그래피·간격을 새로 정의한다.
4. 스타일 가이드 문서를 작성한다: 색상 팔레트(용도별: primary/secondary/배경/텍스트/상태), 타이포그래피(폰트, 크기 스케일), 간격 스케일, 자주 쓰는 shadcn/ui 컴포넌트 목록과 사용 규칙.
5. 문서를 `style-guide.md`로 저장하고, `screen-design-new`·`screen-design-review` 스킬이 참고할 기준 문서임을 안내한다.
6. 이후 디자인 관련 작업 시 이 문서를 기준으로 판단하도록, 기존 문서가 있으면 새로 만들지 말고 갱신 여부만 확인한다.
