# 커밋 메시지 요약 스킬 (commit-summary)

## 🚨 무슨 불편이 있었나요? (Before)
- 매번 코딩 작업이 끝날 때마다 내가 어느 부분을 고쳤는지 일일이 찾아봐야 했습니다.
- 알아낸 내용을 바탕으로 우리 팀 규칙(`[범위] 한 일 (#이슈)`)에 맞춰 요약해서 적으려니 시간이 오래 걸리고 무척 번거로웠습니다.

## ✨ 스킬이 어떻게 해결했나요? (After)
- 이제 스킬 한 번만 실행하면, AI가 알아서 변경된 코드를 확인하고 팀 규칙에 딱 맞는 커밋 메시지로 한 줄씩 깔끔하게 요약해 줍니다!
- 귀찮은 작업이 사라지고, 코딩 마무리 시간이 훨씬 단축되었습니다.
